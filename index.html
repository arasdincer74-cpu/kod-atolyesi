Mini Lab: LED yak-söndür

Elektronikte "merhaba dünya" sayılan blink programı. Beklemeyi değiştir, LED'in nasıl yanıp söndüğünü izle.

// Her mikrodenetleyicide ilk program
void setup() {
  pinMode(D0, OUTPUT);
}

void loop() {
  digitalWrite(D0, HIGH);
  delay(500);
  digitalWrite(D0, LOW);
  delay(500);
}
LOW (söndü)
